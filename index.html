COACHING MEETS ENGINEERING

From Coaching to Coding

Coaching younger players led Vincent to a practical question: how can we tell whether a change in a swing really helped? At Future Stars, short hitting videos, coach observations, targeted drills, and follow-up sessions make feedback more concrete.

Alongside the coaching program, Vincent contributes to the design and testing of an experimental hitting-analysis project. Its public Python prototype uses OpenCV and MediaPipe to explore what two-dimensional video can—and cannot—tell us about movement.

Explore the GitHub Project ↗Development & Limitations

PROJECT STATUS · OCTOBER 2026

Observe. Build. Test.

The latest documented app version, v0.3.8, is being prepared for limited parent/player testing. Android is the current platform; iOS development is underway. The GitHub repository contains the educational Python prototype, methods, and development notes; it is not a download of the local app.

Video-based scores are estimates. Camera angle, visible evidence, and contact-frame selection limit what can be judged. The project is not a validated biomechanics diagnostic tool.
